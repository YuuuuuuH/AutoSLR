# AutoSLR: Project Overview and Weekly Plan

AutoSLR is an agent-assisted system for systematic literature review (SLR). It combines review automation with literature-evolution visual analytics, allowing researchers to inspect evidence and compare methods.


The planned outputs are a working system, reference annotations and experiments, a dissertation, and a reproducible demonstration.
